## Grok：https://www.bullshitprogram.com/en-us/ 深度评价一下

https://www.bullshitprogram.com/en-us/ 这个网站可以一句话总结：

**一个极度中二、极端自恋、故意用英文标题写中文互联网风格“放飞自我”技术随笔 + 抽象段子 + 互联网阴谋论的个人博客。**

核心创作者基本就是同一个人（GitHub: zeusro），从2020年一直写到现在（2026年2月还在更新），内容质量和调性非常一致：**狂拽酷炫吊炸天 + 故意写得很抽象 + 偶尔夹点真技术思考 + 大量自黑/自夸混搭**。

### 内容真实分类（按出现频率排序）

1. **最常见的类型：抽象/搞笑/整活文**（占比60%+）
   - DuckDuckGo game / 一鸭通行：帮小黄鸭预约“鸭场”找富婆，搞黄色代码、美团外卖马甲、Duck王身份这些弱智级抽象梗
   - AI Driven Design Shit Database：AI记录屎的数据做健康分析（项目真做了，还放了GitHub）
   - 《Alarm》All CODE guidelines are bullshit! —— 贯穿全站的slogan

2. **伪深刻技术/未来学宣言**（占比30%）
   - AGI does not exist → 然后马上说编程语言已死，提出“AI Hybrid Programming Model”
   - Chrome Is Dead + Google Search也跟着死
   - One Open Operating System (OOOS)：2020年就喊要用AI重构整个操作系统，做智能API网关
   - P=NP（声称自己证出来了，但实际是抽象文）
   - Service As API、Time-Series Metaprogramming 这些词听起来很酷，但基本都是自创概念，没看到任何可运行的实现或学术级论证

3. **极少数看起来认真的东西**
   - 早期（2020年）对冯诺依曼架构的批评、智能API网关的设想
   - 对云原生OAM规范的吐槽（这个算有点技术含量）

### 深度评价维度打分（满分10）

- **技术深度**：3/10  
  知道一些前沿名词，也能串起来讲故事，但基本停留在“喊口号 + 自创名词”层面，缺少可验证的代码、论文级推导或工业级实践。

- **娱乐性 / 抽象度**：9/10  
  如果你喜欢中文互联网2020-2025那种“弱智吧 + 知乎抽象体 + 技术人自嘲”混合风格，会看得停不下来。Duck系列文章已经接近行为艺术了。

- **自洽性 / 世界观**：8/10  
  他从2020年就坚持一套世界观：AI是终极网关 → 传统编程/浏览器/搜索引擎都会死 → 代码规范都是 bullshit → 人应该“随意编程”。六年了一直在强化这个世界观，没崩。

- **商业化 / 实用价值**：1/10  
  没产品、没付费内容、没招聘、没开源社区，纯个人输出。唯一“产品”可能是那个屎数据库（笑死）。

- **真诚度**：偏高  
  他是真的这么想的，也真的敢把“我要找young and beautiful rich woman”“我是每个游戏的最强玩家”这种话直接写出来，而不是包装成鸡汤或营销文案。

### 最终结论（两种人群的视角）

- 如果你是来找靠谱技术干货/架构方案的 → **绕道，浪费时间**
- 如果你想看一个技术背景的互联网抽象人如何用中英双语持续输出精神状态六年 → **值得收藏，每隔几个月来看看他又整了什么新活**

一句话最狠的评价：

**这不是 bullshit program，这是一个人在用 bullshit 的形式认真地 program 一个属于自己的平行宇宙。** 😭😂
